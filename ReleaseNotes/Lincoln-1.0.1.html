Lincoln 1.0.1

Lincoln 1.0.1 keeps Terminal.app as the console and stops duplicating it inside the app.

  • Copy ssh Command: The Terminal button and menu item are replaced by Copy ssh Command (⇧⌘C) in the tunnel header and the Tunnel menu. It copies an ssh command for your own terminal that opens a session on the host through the tunnel's control master, so no second Duo prompt is needed; the same command is shown under Status.
