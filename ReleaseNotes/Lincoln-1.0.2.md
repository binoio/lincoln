# Lincoln 1.0.2

Lincoln 1.0.2 trims the main window toolbar to the one action that belongs there.

### What's New
- **Simpler toolbar**: Only **New Tunnel** remains in the window toolbar. Diagnostic Logs are reached from **Window › Logs** (⌥⌘L) and the menu bar extra.
- **File › Import from ssh config…** (⇧⌘I) opens the import sheet; the empty-state button still offers it on first run.
